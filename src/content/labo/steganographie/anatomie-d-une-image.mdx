{/*
  Ton texte ici. Une proposition de plan, à réécrire à ta façon :

  1. Une image n'est qu'un tableau de nombres : chaque pixel vaut de 0 à 255.
  2. Chaque nombre s'écrit avec 8 bits, et chaque bit n'a pas le même poids.
     Le plan 7 pèse 128, le plan 0 pèse 1.
  3. Ce qu'on voit en parcourant les plans : les formes tiennent dans les plans
     lourds, les plans légers ressemblent à du bruit.
  4. Pourquoi c'est là qu'on cache : changer le plan 0 ne modifie un pixel que
     d'une unité, invisible à l'œil.
  5. Le contre-exemple du dégradé lisse : même le plan 0 y garde un dessin
     régulier. Un message caché y briserait cette régularité.
     <AnatomieImage exemple="degrade" plan={0} />
  6. L'histogramme : il résume l'image en comptant ses valeurs. On s'en
     servira pour détecter un message.

  Information, aéroport Aden Adde de Mogadiscio. Licence CC0, Wikimedia Commons.
